# LAPRIEST — Arquitectura de Alta Costura Brutalista

> **Estética Brutalista Oscura, Alto Contraste, Editorial y Minimalista**  
> Referencias cruzadas: **MUBI**, **032c** y **Rick Owens**.  
> **Directiva de Comercio Electrónico:** Cero carritos de compra, cero pasarelas de pago WooCommerce, cero botones "añadir a la bolsa". Sistema de ofertas y propuestas directas de adquisición.  
> **Idioma:** 100% Español Latinoamericano / Neutral.  
> **Tipografía Oficial de Títulos:** **SF Pro Display** (Opción 3 seleccionada).  
> **Crédito de Autoría:** *Friendly Dev by Shon* con efecto respiratorio blanco / púrpura / negro.

---

## ⚡ Ejecución Rápida sin Entrar a Antigravity

Puedes encender y apagar el servidor local con solo hacer **doble clic** en estos dos archivos desde Windows:

1. 🟢 **`ARRANCAR-SITIO.bat`**:  
   Inicia el servidor local en el puerto `3000`, muestra la dirección y abre automáticamente tu navegador en **`http://localhost:3000/`**.
2. 🔴 **`DETENER-SITIO.bat`**:  
   Apaga el servidor de inmediato y libera el puerto `3000` con un solo clic.

## 📸 Función Especial: Modo Captura Limpia
En la parte superior de cada página hay una barra curatorial flotante para alternar entre versiones. Para sacar capturas 100% limpias:
* Haz clic en el botón **[ MODO CAPTURA LIMPIA ]** en la barra superior.
* O presiona la tecla **C** en tu teclado.
* La barra desaparecerá instantáneamente permitiendo capturas impecables de pantalla completa.
